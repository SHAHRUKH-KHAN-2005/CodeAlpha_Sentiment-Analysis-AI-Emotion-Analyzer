📌 About the Project

Sentiment Analysis – AI Emotion Analyzer is a Machine Learning-based application designed to analyze textual input and identify sentiment or emotional patterns expressed through text.

The project combines Python, Machine Learning, and an interactive interface to provide an accessible way to explore text-based sentiment analysis.

✨ Features

- 📝 Analyze text input using Machine Learning.
- 🧠 Predict sentiment or emotion from textual content.
- ⚡ Interactive user interface.
- 🤖 Trained Machine Learning models.
- 📊 Text processing and feature extraction.
- 🎨 User-friendly application experience.

🛠️ Technologies Used

Technology| Purpose
Python| Core programming language
Streamlit| Interactive web application
Scikit-learn| Machine Learning
Pandas| Data processing
TF-IDF| Text feature extraction
Joblib| Model loading

⚙️ Installation & Setup

Step 1: Clone the repository

git clone https://github.com/SHAHRUKH-KHAN-2005/Sentiment-Analysis-AI-Emotion-Analyzer.git

Step 2: Navigate to the project folder

cd Sentiment-Analysis-AI-Emotion-Analyzer/SentimentAnalysisProject

Step 3: Install dependencies

pip install -r Requirements.txt

Step 4: Run the application

streamlit run app.py

The application will launch in your browser.

🚀 How to Use

1. Run the application using Streamlit.
2. Enter your text into the application's input field.
3. Submit the text for analysis.
4. View the generated sentiment or emotion prediction.
